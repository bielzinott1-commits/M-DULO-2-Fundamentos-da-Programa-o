# Introdução

Antes de aprender qualquer linguagem de programação, existe uma habilidade que todo programador precisa desenvolver:

## Pensar logicamente.

Muitas pessoas acreditam que programar é decorar comandos:

```javascript
console.log("Olá");
```

ou:

```python
print("Olá")
```

Mas isso é apenas uma pequena parte.

A verdadeira programação começa antes do código.

Um programador primeiro pensa:

> "Qual problema preciso resolver?"
>
> "Quais passos são necessários?"
>
> "Como transformar essa solução em instruções que o computador entenda?"

Essa forma de pensar é chamada de:

# Lógica de Programação

---

# O que é lógica?

Lógica é a maneira organizada de pensar para chegar a uma conclusão ou resolver um problema.

Ela está presente no nosso dia a dia.

Exemplo:

Problema:

> "Preciso sair de casa e chegar ao trabalho."

Pensamento lógico:

```
1. Acordar
2. Tomar banho
3. Se vestir
4. Pegar transporte
5. Ir até o trabalho
```

Você criou uma sequência de passos.

Isso já é um algoritmo.

---

# O que é programação?

Programação é o processo de criar instruções para que um computador execute uma tarefa.

O computador não entende pensamentos.

Ele entende:

* comandos;
* regras;
* sequências;
* dados.

O programador transforma uma ideia em instruções.

---

# Programador x Computador

Um humano entende:

> "Faça um café."

Mas o computador precisa de detalhes:

```
1. Pegar uma xícara
2. Colocar café em pó
3. Adicionar água quente
4. Misturar
5. Servir
```

Quanto mais precisa for a instrução, melhor o resultado.

---

# O que é um algoritmo?

Um algoritmo é uma sequência de passos organizados para resolver um problema.

Ele não precisa estar em uma linguagem de programação.

Pode ser escrito em:

* português;
* desenho;
* fluxograma;
* pseudocódigo;
* código.

---

# Exemplo de algoritmo

Problema:

Calcular a média de um aluno.

Passos:

```
1. Receber nota 1
2. Receber nota 2
3. Somar as notas
4. Dividir por 2
5. Mostrar resultado
```

Esse é um algoritmo.

Depois podemos transformar em código.

# O pensamento computacional

Pensamento computacional é uma forma de resolver problemas utilizando conceitos da computação.

Ele possui quatro pilares principais.

---

# 1. Decomposição

É dividir um problema grande em partes menores.

Exemplo:

Criar um aplicativo de loja.

Problema grande:

```
Criar aplicativo
```

Dividindo:

```
Cadastro de usuários

Login

Produtos

Carrinho

Pagamento

Entrega
```

Agora o problema ficou mais fácil.

---

# 2. Reconhecimento de padrões

É encontrar semelhanças entre problemas.

Exemplo:

Você percebe que:

* Instagram;
* Facebook;
* TikTok;

todos possuem:

* usuários;
* login;
* fotos;
* curtidas.

Então você pode reutilizar ideias.

---

# 3. Abstração

É focar no que importa e ignorar detalhes desnecessários.

Exemplo:

Quando você usa um celular, você não precisa saber:

* como o processador funciona;
* como os elétrons passam pelos circuitos.

Você apenas usa:

* tela;
* aplicativos;
* botões.

---

# 4. Algoritmos

É criar uma sequência lógica para resolver o problema.

Exemplo:

```
Receber dados

Processar informações

Mostrar resultado
```

---

# Entrada, Processamento e Saída (IPO)

Todo programa possui três etapas principais:

# Entrada

Dados fornecidos pelo usuário ou sistema.

Exemplos:

* teclado;
* mouse;
* câmera;
* banco de dados.

---

# Processamento

O programa realiza operações.

Exemplo:

* cálculos;
* comparações;
* decisões.

---

# Saída

Resultado apresentado.

Exemplos:

* tela;
* arquivo;
* mensagem;
* relatório.

---

## Exemplo:

Sistema de login:

Entrada:

```
Usuário
Senha
```

Processamento:

```
Verificar dados
```

Saída:

```
Acesso permitido
```

# Como um programador resolve problemas

Um método profissional:

## 1. Entender o problema

Pergunte:

* O que precisa ser feito?
* Quem utilizará?
* Qual resultado esperado?

---

## 2. Planejar a solução

Antes de programar:

* escreva passos;
* faça desenhos;
* organize ideias.

---

## 3. Criar o algoritmo

Transforme a solução em sequência lógica.

---

## 4. Programar

Escolha uma linguagem.

Exemplo:

* JavaScript;
* Python;
* Java;
* C#.

---

## 5. Testar

Verifique:

* funciona?
* possui erros?
* pode melhorar?

---

# Exemplo prático

Problema:

Criar um programa que verifica idade.

---

## Algoritmo:

```
Início

Receber idade

Se idade for maior ou igual a 18

Mostrar "Maior de idade"

Senão

Mostrar "Menor de idade"

Fim
```

---

Depois transformamos em código.

Exemplo JavaScript:

```javascript
let idade = 20;

if(idade >= 18){

console.log("Maior de idade");

}else{

console.log("Menor de idade");

}
```
